# Coaching workflow upgrade - 2 November 2026

## Connected preparation
From a sourced series or team profile, prepare a local scouting report. Record observations and hypotheses separately, including source, timestamp, sample and version. Send selected evidence and a match brief to the draft builder. Explain the win condition, resource requirements, player comfort, responsibilities and fallback. Capture a draft snapshot back into the report or carry it into map planning.

The planner retains the existing textured map references and coordinates. Capture separate Setup, Trigger, Execution, Fallback and alternative canvases. Each phase has a trigger, team call, responsibilities and interpretation. Inspector classifications distinguish planned, observed and hypothetical annotations; these are coach-entered labels, not independent verification. Attach the playbook to its report for post-match review. JSON retains editable phases; print/PDF presents coaching sheets; PNG exports the active canvas.

## Individual improvement
The Counter Lab compares sourced kits with five problem-based decision frameworks. Individual responses, coordinated responses, swap costs and disconfirming evidence lead to an Academy drill and journal focus. No automatic counter score is invented.

Eleven original Academy lessons cover kits, positioning, timing, cooldowns, teamwork, resets, drafting, review, controller practice, patch assessment and session habits. Examples are labelled illustrations. Each lesson provides a drill, assessment and cue. Existing lesson IDs and review progress remain supported.

The journal retains old records and adds map, timestamp, controllable adjustment, next action, self-observed habit tags and explicit focus adherence. Missing observations remain unknown. Counts are derived only from personal entries and do not establish causation or global rank expectations. Session boundaries are personal reminders, not enforced queue controls.

## Saving, sharing and privacy
Work is browser-local unless the user explicitly uses an existing optional cloud feature. Save failures and concurrent-tab conflicts are visible; pending tool edits survive navigation within the current app session. Export before leaving after a save warning. Existing corrupt storage is not overwritten.

Map share links open a read-only snapshot. Recipients can explicitly open an editable copy or download it: view-only is not access control or confidentiality. Links contain their snapshot contents. JSON imports require review before replacing a draft or plan and support Undo. Journal imports merge valid records and preserve conflicting IDs. Journal exports also retain focus/context/boundary fields for reference; merging matches does not replace the current focus or boundary. Reports, journal entries and captures have local undo/recovery controls. Backups remain important.

## Shared interface
All eighteen navigation destinations and existing media remain. Goal-based home links, expandable sample filters, page guidance, presentation controls, visible focus states, reduced-motion support and mobile layouts connect the tools. Feedback copying is explicit and excludes report contents; optional diagnostics contain only route and viewport size.

## Evidence and limits
This release adds original educational frameworks and workflows, not a fresh competition-data scrape. Existing data retains its source/review dates and Monday update cadence. No new health-pack or spawn positions, map geometry, individual statistics or live-game mechanics were inferred. Current footage and independently verified interactions are still required for matchup conclusions. A real public portfolio case study requires the owner's actual reviewed work and publishing choice; private reports are never automatically showcased.

Core workflows require no new paid service or account. Existing optional live rooms and private cloud backup retain their existing configuration and limitations. Playbooks have bounded sizes; exceptionally large uploaded images may require a separate JSON export rather than phase capture or a URL.
